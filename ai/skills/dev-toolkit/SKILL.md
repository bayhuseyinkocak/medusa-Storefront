# Medusa dev toolkit

| Task | Command |
|------|---------|
| Install | `pnpm install` |
| Dev | `pnpm dev` |
| Build | `pnpm build` |
| Test | `pnpm test` |
| Migrate | `npx medusa db:migrate` |
| Sync agents | `ide-agent sync` |
| Pull skills | `ide-agent pull-skills` |

Run tests after backend changes. Run migrations after schema updates.
